# RescuGrid

RescueGrid is a Java-based Disaster Rescue Coordination System designed to improve emergency response during natural disasters such as floods, earthquakes, landslides, and building collapses. During such situations, people may struggle to communicate their needs, and rescue teams may face delays due to inaccurate locations, poor connectivity, and a lack of timely information.

The main objective of RescueGrid is to **identify the precise available location of an incident and communicate the required assistance to rescue teams as quickly as possible.** The system organizes distress requests, records incident details, prioritizes emergencies based on urgency, and supports rescue-team assignment and incident tracking. It aims to provide a simple reporting process that can be easily used by children, older adults, and people in distress.

Developed using Java, the project demonstrates important object-oriented programming concepts, including abstraction, inheritance, polymorphism, encapsulation, interfaces, exception handling, collections, priority queues, and file handling. It also explores offline incident storage and future integration with independent communication technologies to support reporting when conventional networks are unavailable.

Overall, RescueGrid aims to provide a foundation for a faster, more accessible, and better-coordinated disaster-response system.
